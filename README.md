# ☀️ OptiSun

OptiSun est une boutique e-commerce spécialisée dans les solutions d'énergie solaire et les équipements photovoltaïques.

L'application permet aux utilisateurs de consulter un catalogue de produits, d'ajouter des articles au panier et de gérer leurs achats via une interface simple, moderne et responsive.

## 🌍 Démonstration

Application en ligne :

https://optisun.vercel.app/

## 🚀 Fonctionnalités

### Catalogue produits
- Affichage des produits solaires
- Présentation détaillée des équipements
- Images et informations techniques

### Panier d'achat
- Ajout de produits au panier
- Modification des quantités
- Suppression d'articles
- Calcul automatique du total

### Persistance des données
- Sauvegarde du panier via LocalStorage
- Conservation des données même après fermeture du navigateur

### Responsive Design
- Compatible ordinateur
- Compatible tablette
- Compatible smartphone

## 🛠 Technologies utilisées

### Front-end
- HTML5
- CSS3
- JavaScript Vanilla

### Hébergement
- Vercel

### Stockage
- LocalStorage (navigateur)

## ⚙️ Installation locale

### Cloner le projet

```bash
git clone https://github.com/DidierThebaut/Optisun.git
```

### Accéder au dossier

```bash
cd Optisun
```

### Lancer l'application

Ouvrir simplement :

```bash
index.html
```

ou utiliser un serveur local :

```bash
npx serve
```

- Gérer un panier d'achat avec LocalStorage.
- Déployer une application statique sur Vercel.
